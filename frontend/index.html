Welcome to RedisGen!

RedisGen is your sleek, high-performance, in-memory data store dashboard. With its new Neumorphism (Soft UI) design, interacting with your database is not only powerful but also visually stunning.

Let's take a quick tour of your new tools!

Connection & Database

  • Auto-Connect: The dashboard automatically connects in the background. Look for the green Connected badge!
  • Database Selector: Use the top right dropdown (db0-db15) to isolate keys in different logical databases.
  • Disconnect: Manually sever the connection using the Disconnect button.

Server Stats

Get a real-time pulse on your database's health.

  • Memory & Clients: Live metrics on RAM consumption and active connections.
  • Total Keys: Number of keys stored in the active database.
  • Memory Chart: A live-updating sparkline visualizing memory usage over time to help spot leaks at a glance.

Interactive Terminal

Direct command-line access to your RedisGen instance.

  • Run Commands: Type standard Redis commands like PING or SET mykey "Hello".
  • Instant Feedback: Green for successful responses, Red for errors.
  • History: Use the Up and Down arrow keys to cycle through previous commands.

Key Browser

Manage your data visually without needing to remember every key name.

  • Search & Scan: Filter keys using pattern matching (e.g., user:*) and hit the Scan button.
  • Type Badges: Every key has a colored badge indicating its data structure (String, List, Hash, Set, ZSet).
  • Detail View: Click any key to automatically fetch and display its formatted JSON contents in the right pane.

Enjoy your new dashboard!
